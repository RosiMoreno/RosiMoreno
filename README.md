### 🌧️ Climate trends in Barcelona
**Python | Pandas | Numpy | Scipy | Matplotlib | Seaborn |Power BI**

### 💧 Hydrogeochemical Analysis & Geothermometers
**Python | Hydrogeochemistry | Jupyter Notebook**

Development of Python tools for hydrochemical data processing, ionic ratio calculations, geothermometer estimation, and hydrogeochemical interpretation of groundwater and thermal water systems.

Main analyses include:

- Water-rock interaction assessment
- Hydrothermal system characterization
